# MSI G273Q 标准适配

仅匹配 MSI/0x3CA8 / MSI G273Q。亮度、对比度、RGB 已内置，不重复添加整套同名功能。此包补充色温可写范围/联动声明，以及0xDC应用预设标准文字；不是未知私有协议的破解包。

导入adapter.json/ZIP → 应用到副屏。首次应用时自动采用包内色温定义，无需额外选择；已有明确来源选择保留。其他标准功能继续用standard。当前只开放标准6500K(5)和用户色温(11)，其中本次实机只读观察5；SET尚未执行，writable为标准协议声明，不能称为MSI实机写入认证。0xDC回读2/11，按MCCS解释为混合用途，并不证明MSI OSD中这个模式的名字；保持只读。

两轮只读亮度75/100、对比度70/100、色温5/11、输入DP1及RGB50/100成功。0x72伽马、0x87锐度、0x86图像比例两轮未读到，未加入可写控件，也不能据此证明OSD没有相应功能。USB msigd支持表未找到G273Q，未把其他型号USB报文套到本机。

原始验证与资料索引见docs/MONITOR_ADAPTER_VALIDATION.md。安装不自动运行/绑定/写硬件，不改主屏包。
