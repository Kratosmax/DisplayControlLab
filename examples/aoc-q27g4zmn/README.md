# AOC Q27G4ZMN 型号适配 1.5.0

一个包包含主屏全部已接入的型号功能：11项私有功能，以及标准接口的游戏模式、图像比例、AOC色温定义。亮度/对比度/RGB等基础项继续复用控制器内置目录。主屏仅需此包，不需要额外标准补充包。

先使用支持功能级backend的新控制器，导入ZIP → 应用到主屏。首次应用自动采用厂家色温定义；已有明确来源选择保留。更新同id包使用导入预览的替换操作。若本机曾装过试验性的旧补充包，卸载它即可；当前没有版本迁移逻辑。

包默认amd-ddc，三项标准功能声明backend=standard-ddc。1.5.0开放完成实机回读及原值恢复的生态调节、DCR，补齐伽马、Overdrive、低蓝光的验证档位。游戏色调、暗场按设备返回的0–20范围调节，实测边界与中间样本，不称每个整数均已测试。生态最后一档修正为“均匀亮补偿”。保留设备/HDR互锁及写后回读。

1.5.0新增低输入延迟、准星开关；帧计数器开放关闭、右上、右下，左侧两档存在写入/回读编码互换，未核实实际位置，暂不开放。三项仅在系统SDR且显示器HDR关闭时可写。游戏模式、比例仍只读；区域调光、色彩空间、Adaptive-Sync仍待有效协议，不宣称覆盖全部OSD。功能说明列出具体限制，伽马最终档位及测试边界见docs/OSD_CONTROL_VALIDATION.md。没有新增NVIDIA/Intel私有传输；没有AMD时标准项仍可读取，冲突写入要求HDR状态已知。

本地预览，非正式Release。需导入本轮ZIP、替换已安装的同id包，再应用到主屏；启动新版exe不会自动更新用户安装包。
