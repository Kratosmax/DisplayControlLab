# 本地重构预览验收

2026-10-11，.NET 8 / Windows x64 / WPF。此文件记录实现与证据边界，不把静态设计图或历史测试当成新产品验证。未提交、未推送、未发布；正式版本号未改。

## 实现范围

两个入口已替换为共享工作区：按类型控制、收藏/昵称、条件与来源、方案预检/顺序应用/部分失败、持久化历史和冲突恢复、快照比较、分段/连续实验、标记与边界修订、重开/证据导出、包管理、表单/条件协议工作台、主动测试、单实例上下文导航。

Core/Workspace.cs 负责方案、控制、恢复与比较；Routing.cs 负责多提供者与内容信任；DeviceControl.cs 保留真实工作进程/硬件串行/协议校验；UI 页面共用以上服务。Reader/Controller 不再各持一套窗口或业务。

删除旧 Controller/MainWindow.xaml(.cs)、Reader/MainWindow.xaml(.cs)、ReadSession.cs、AuditLog.cs、ObservationStore.cs、Tests.cs、GlobalUsings.cs；原始 native/ADL 算法保留在 Core。已删 --self-test/旧日志重置/临时恢复入口，CI、教程改用新测试。

Models.cs 中 DdcResult/FeatureRow/ChangeRecord 保留用于原生诊断与旧记录数据兼容，不再运行旧会话逻辑。state.json bindings 只兼容读入；新绑定走 devicePackages。历史发布说明和 temp 中原始实验/回滚快照是证据，不是产品活跃实现，不删除。

## 尚未验证或不在本轮范围

- 区域调光、色彩空间、Adaptive-Sync、设备游戏模式、图像比例：菜单已知，真实私有读写待适配。
- 新工作台的实机写入/屏幕视觉效果与恢复需要用户主动操作；本轮自动验证保持只读。
- 实际厂商封闭 SDK、其他显卡/固件/型号/特殊校验：必须由相应包/插件验证；复杂协议不硬塞固定帧解释器。
- 插件可 probe/describe 并返回动态描述作诊断，但当前安装清单仍为控制路由来源，描述不会自动改用户配置。
- 不含在线商店、云同步、托盘自启、全局快捷键、自动更新；未做这些功能的空入口。
- 本机无 Inno Setup 编译器，交付本地 Lite ZIP/直接运行目录，不宣称安装器实测。

独立插件结构适合专有驱动。边界是厂商 SDK 不允许第三方调用或设备协议未知时，宿主和插件格式本身无法创造控制能力。




## 旧包与预检提示修复（2026-10-11）

用户现有旧 HDR 包缺少 valueType，被默认 number 渲染为数字输入，但 rules 要求模式名称，导致数字值被预检拒绝。新增兼容解析：缺少类型且有命名规则时按枚举；显式数字类型带命名规则也使用选项控件。预检失败在功能旁和状态栏显示具体功能、原因，不绕过限制。

本轮 96 项核心与 25 项离屏 UI 测试通过；证据 temp/validation/preflight-fix。用用户旧包副本实机只读 15 项成功，HDR 正确为枚举，原包文件未修改，没有发送设置。实际写入效果仍由用户主动操作验证。
