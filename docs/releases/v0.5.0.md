# DisplayControlLab 0.5.0

本版保留已有用户资料。旧版若下载完成后停在“准备安装”，请退出读取器和控制器，使用本版安装包或解压 ZIP 手动升级；旧版退出问题尚未完全复现，新版增加交接日志和状态保护。

- 控制页每台显示器统一选择一个协议包，显示包名，移除各功能重复的来源下拉；选中包未覆盖项目不混入控制页。
- 可给色温、画面预设等选项命名并保存，名称随控制包导出；已知标签不再被临时编码覆盖。
- 对比表使用最新名称并保留编码；单项重读就地移动强调行，整页读取保留功能面板及折叠状态。
- 重新检测沿用相同设备、协议来源和有效条件下的本机写入证明及名称；条件改变保留名称并提示重试。连续单档成功测试累计通过档位。
- 手动测试图像预设复用专用联动恢复，画面预设测试后检查并恢复原色温和图像项；恢复提示列出未恢复项目与当前/目标值。
- 更新交接后自动请求退出，阻止重复更新与迟到进度覆盖；失败清除过期进度，记录准备、启动和退出阶段。

未知协议不猜码试写，未验证或受恢复影响的项目不进入控制包。读数联动不等于实际菜单或声音变化；标准名称可能与厂商菜单不同，可按实际菜单改名。识别码匹配范围未扩大，Dell P2419H 的 DP/HDMI 识别码不同，现有包不会自动获得另一连接的验证。

下载：Full Setup / Full ZIP 自带运行库；Lite Setup / Lite ZIP 需要 .NET 8 Desktop Runtime x64。提供两通道签名更新清单、兼容清单及 SHA256SUMS.txt。更新前退出另一工具并等待显示器操作完成。
